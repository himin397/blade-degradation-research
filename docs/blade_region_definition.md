# ブレード部位定義ドキュメント

作成日: 2026-04-01
対象フェーズ: Phase 1 W07

---

## 1. 部位定義の考え方

DTUデータはドローンで撮影したブレード表面の画像。
「どの部位に損傷が出たか」を定量化するために、ブレードを部位に分割する。

### 2軸での分割

```
ブレードの部位は「スパン方向」×「コード方向」の2軸で定義する。

スパン方向（根元→先端）:
  Root（翼根）: 0〜33%
  Mid（中間）:  33〜67%
  Tip（翼端）:  67〜100%

コード方向（前縁→後縁）:
  LE（Leading Edge）:  前縁側25%
  Body（胴体面）:      中央50%
  TE（Trailing Edge）: 後縁側25%
```

### 組み合わせ（6領域）

| 部位ID | 名称 | スパン | コード | リスク特性 |
|---|---|---|---|---|
| R-LE | 翼根前縁 | Root | LE | LEE発生は少ないが補修困難 |
| R-Body | 翼根胴体 | Root | Body | 比較的安全 |
| M-LE | 中間前縁 | Mid | LE | LEE中程度・最も観察しやすい |
| M-Body | 中間胴体 | Mid | Body | VGパネル多い |
| T-LE | 翼端前縁 | Tip | LE | **最高リスク**（線速度最大・LEE集中）|
| T-Body | 翼端胴体 | Tip | Body | 比較的安全 |

**T-LE（翼端前縁）が最重要領域**：
- 翼端は線速度が最も高い（例：80m径タービンで風速10m/sの場合、翼端速度は約80m/s超）
- 雨滴・砂・虫との衝突エネルギーが最大
- LEEが最も進行しやすい部位
- himinさんの現場経験とも一致する知見

## 2. 画像上での部位マッピング方針

DTU画像はブレード全体を複数枚で撮影している。
1枚の画像に「ブレードのどの部分が写っているか」を推定するためのアプローチ。

### アプローチA：ファイル名・撮影順序から推定（シンプル）
同一ブレードの画像を撮影順にソートし、前半→Root、後半→Tipと仮定する。
精度は低いが実装が簡単。

### アプローチB：バウンディングボックスのx座標から推定（中程度）
画像内での損傷のx座標位置から「前縁寄りか後縁寄りか」を推定する。
ドローンの撮影方向が統一されている場合に有効。

### アプローチC：ブレード輪郭検出から推定（精度高・実装重い）
画像処理でブレードのシルエットを検出し、前縁・後縁・先端・根元を特定する。

**本研究での採用方針**：
まずアプローチBで実装し、精度確認後にCを検討する。

## 3. 各損傷クラスと部位の関係

| クラス | 最も発生しやすい部位 | 理由 |
|---|---|---|
| LE;ER（前縁浸食） | T-LE, M-LE | 線速度・衝突エネルギーが高い前縁・翼端 |
| LE;CR（前縁クラック） | M-LE, T-LE | 浸食が進行してクラックに発展 |
| VG;MT（VG欠損） | M-Body | VGパネルは主に中間部の胴体面に設置 |
| LR;DA（受雷部損傷） | T-Body | 受雷部は翼端付近に設置されることが多い |
| SF;PO（表面損傷） | 全部位 | 広範囲に発生 |

*注記：上記は仮説止まり。DTUデータの分布確認後に更新する。*

## 4. リスクスコアへの接続（W08への橋渡し）

部位定義が確定したら、次のステップでリスクスコアを算出する。

**スコアの構成要素（案）**：
```
部位別リスクスコア = Σ（信頼度 × 損傷面積比率 × クラス重み × 部位重み）
```

| 要素 | 説明 |
|---|---|
| 信頼度 | YOLOv8の検出信頼度（0〜1） |
| 損傷面積比率 | バウンディングボックスの面積 ÷ 画像面積 |
| クラス重み | 損傷の重篤度による重み（LE;ER > SF;PO など） |
| 部位重み | 部位のリスク係数（T-LE > M-LE > R-LE など） |

**クラス重み（案）**：

| クラス | 重み | 根拠 |
|---|---|---|
| LE;CR | 3.0 | クラックは構造上最もリスクが高い |
| LE;ER | 2.0 | 浸食はAEP損失・進行リスクあり |
| VG;MT | 1.5 | 空力性能への影響あり |
| LR;DA | 1.5 | 落雷保護への影響 |
| SF;PO | 1.0 | 表面汚染・軽微な損傷 |

**部位重み（案）**：

| 部位 | 重み | 根拠 |
|---|---|---|
| T-LE | 3.0 | 最高リスク（線速度最大・LEE集中） |
| T-Body | 1.5 | 翼端だが前縁ではない |
| M-LE | 2.0 | 前縁・中間 |
| M-Body | 1.0 | 中間・胴体 |
| R-LE | 1.5 | 前縁・翼根 |
| R-Body | 1.0 | 翼根・胴体 |

*注記：これらの重みは現場経験から設定した仮説。将来的に論文データや補修履歴と照合して調整する。*
