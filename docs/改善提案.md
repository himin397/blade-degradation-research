# 改善提案箱（親フォルダ claude1 への共有・追記専用）

このファイルは、このフォルダで気づいた**運用ルールの改善点・失敗事例・便利な工程**を親（claude1）に共有するための提案箱です。子フォルダは他フォルダを編集できないので、ここに書く → 親が `/sync-rules` で回収 → 採否 → 全フォルダへ反映、の一方向で流れます。

## 書き方（`/propose` で型どおりに追記できる）
- **このファイルは追記専用**。処理状態（未処理／反映済み／却下／保留）は親の台帳 `claude1/AIノート/共有知見台帳.md` が管理する。親もこのファイルを書き換えない
- 1件1節。見出し＝`## ID: blade-YYYYMMDD-NNN | 種別 | YYYY-MM-DD`（NNN は同日の連番 001〜）。台帳に同じ ID が載っていなければ「未処理」
- 種別＝失敗事例／改善案／工程（フック・スキル・テンプレート）／知見（ツール・手順）
- **守秘区分D の汎用知見だけ書く**。勤務先由来のデータ・サイト名・機器ID・未公開の研究結果は書かない。研究の中身ではなく「進め方」の知見を書く（このファイルは親が読む）
- 追記の前に既存の節を読み、同趣旨があれば新規節を作らず「同事例を再発（日付）」と1行足す

型：
```
## ID: blade-YYYYMMDD-NNN | 種別 | YYYY-MM-DD
- **内容**：（1〜3行。何を変えると何が良くなるか）
- **根拠・経緯**：（何が起きたか。何で捕捉したか。再現条件）
- **提案する反映先**：CLAUDE.md の節 ／ フック ／ スキル ／ メモリ ／ テンプレート
- **適用範囲**：全フォルダ ／ 特定フォルダ（理由）
```
