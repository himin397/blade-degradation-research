### Step 1.5：データ粒度・結合条件・公開データの限界

| 理解すべきこと | 内容 |
|---|---|
| 画像の粒度 | 1枚、1パッチ、1時点。DTUデータはturbine_id × monthを持たない |
| SCADAの粒度 | 10分値、月次集約、タービン別。Penmanshielは10分値を持つ |
| 統合に必要なキー | turbine_id, month/date, 可能なら blade_id |
| なぜ公開データだけでは統合が成立しないか | DTU（画像）とPenmanshiel（SCADA）は別タービン・別サイト |
| どういうデータが揃えば修士研究が成立するか | 1タービン × 2時点画像 + 同期間SCADA + 補修履歴 |

数学は不要。研究のボトルネックの本質理解。

**合格ライン**: なぜ same-turbine data が必要か説明できる

---

### Step 2：風の物理と風車の基礎

| 理解すべきこと | 数学的背景 |
|---|---|
| 風速の確率分布 | **Weibull分布**: なぜ正規分布ではなくWeibullなのか |
| 乱流強度 (TI) | σ_V / V̄ の意味。なぜ10分平均か。IEC 61400-1 の定義 |
| パワーカーブ | P = ½ρAV³Cp の意味。Cp_max が性能指標になる理由 |
| カットイン/定格/カットアウト | 運転領域ごとに荷重の性格が変わる理由 |

**合格ライン**: TI と Cp_max を言葉で説明できる

---

### Step 3：疲労と荷重の基礎

| 理解すべきこと | 数学的背景 |
|---|---|
| 疲労とは何か | S-N曲線（応力-寿命曲線）。繰り返し荷重で材料が壊れるメカニズム |
| Rainflow counting | 不規則な荷重波形を「何回、どの振幅で繰り返したか」に分解する方法（ASTM E1049） |
| DEL (Damage Equivalent Load) | DEL = (Σ nᵢ Sᵢᵐ / N_eq)^(1/m) の意味 |
| Wöhler指数 m | 材料特性。m=10（複合材）の意味 |

**合格ライン**: DEL が「荷重履歴を1つの等価振幅に潰したもの」と説明できる

---

### Step 4：OpenFAST と DLC の意味（Step 5 より優先度やや高）

| 理解すべきこと | 背景 |
|---|---|
| 空力弾性シミュレーションとは | 風 → ブレード変形 → 荷重のフィードバックループ |
| なぜOpenFASTを使ったか | 実機にセンサーを付けられない → シミュレーションで荷重を「作る」 |
| DLC (Design Load Case) | IEC 61400-1 が定める設計荷重条件。DLC 1.2（通常発電）が基本 |
| NREL 5MW → MM82 スケーリング | λ_R = R_MM82/R_5MW = 0.651。なぜ必要か |
| DELマトリクス (8V × 5TI) | 風速×TIのグリッドでDEL整理 → SCADAからDELを逆引きするルックアップテーブル |

**合格ライン**: OpenFAST で何を作っていて、DEL matrix が何に使われるか説明できる

---

### Step 5：画像検出の基礎（Step 4 と並行可能）

| 理解すべきこと | 数学的背景 |
|---|---|
| 物体検出とは | 画像中の「どこに」「何が」あるかを同時に推定する |
| YOLOの基本思想 | 画像をグリッドに分割し、各グリッドでBBox + クラス確率を一度に出力（1-stage） |
| IoU (Intersection over Union) | 予測BBoxと正解BBoxの重なり度合い |
| Precision / Recall | 「見つけたものの正しさ」と「正解を見つけた割合」 |
| mAP@0.5 = 0.58 の意味 | IoU≥0.5 で、全クラス平均のPR曲線下面積が58% |
| ピラミッドパッチ拡張 | 高解像度画像を複数スケールのパッチに分割して小さな損傷を拾う工夫 |

**合格ライン**: mAP@0.5 = 0.58 が何を意味するか説明できる

---

### Step 6：リスクスコアと統合の論理

| 理解すべきこと | 背景 |
|---|---|
| スパン方向リスクスコア | Tip/Mid/Root の重み（3:2:1）が「先端ほど荷重大」という物理に基づく |
| 正規化 (0–1) | 異種指標を統合するために同じスケールに揃える |
| α × image + β × fatigue | 線形結合。等重みは暫定。なぜ非線形でないか → データがないから |
| w_V/w_TI と α/β の違い | 同一物理量内の較正（回帰で可能）vs 異種情報間の較正（補修記録が必要） |

**合格ライン**: α/β と w_V/w_TI の違いを説明できる

---

### Step 7：実データとの照合（Penmanshiel）

| 理解すべきこと | 背景 |
|---|---|
| TI直接計測 vs bin-averaged | 10分σ/V（~0.14）vs ビン近似（~0.035）。4倍の差 |
| 月次DELの季節性 | 冬季（2月）ピーク。風況年変動が主因 |
| 台間比較（T01-T06） | 同一サイトでもCp_max, AEPに差 → ウェイク効果・制御差 |
| 縦断分析（2016-2021） | DEL増加は劣化ではなく風況変動。Cp_max増加（劣化なし）と整合 |

**合格ライン**: Penmanshiel データから「何が言えて何が言えないか」を区別できる

|---|---|
| 最小成功ライン | 1タービン × 2時点画像 + SCADA + 補修履歴 → 統合が単独指標より説明力が高いか |

**合格ライン**: 修士研究の最小成功ラインを自分の言葉で言える
