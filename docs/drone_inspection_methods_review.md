## 1. ドローン点検の全体像

### 1.1 点検対象：4面 × 3枚（スパン基準）

【観察】ブレード1枚につき4つの面を、根元(root)から先端(tip)まで系統的に撮影する。

| 面 | 英語 | 主な損傷 | 研究との関係 |
|---|---|---|---|
| 前縁 | Leading Edge (LE) | エロージョン、雷 | **エロージョン研究の主対象** |
| 後縁 | Trailing Edge (TE) | 接着ライン割れ、スプリット、セレーション脱落 | — |
| 圧力面 | Pressure Side (PS) | 表面クラック、塗装損傷 | — |
| 負圧面 | Suction Side (SS) | クラック、雷損傷 | — |

撮影順は一般に PS → SS → LE → TE。3枚分を繰り返す。

### 1.2 工程：撮影と判断が分離する

【観察】ドローン点検は次の3段階に分かれる。

```
[1] 網羅撮影         [2] 解析・トリアージ      [3] 接触確認・補修
ドローンが全面・    画像レビュー/AIで      疑い箇所をロープ
全スパンを均一に    損傷を抽出・区分      アクセスで打音確認
撮る                                      ・補修
```

【仮説】望遠鏡・ロープ点検では「どこを重点的に見るか」を**撮影前に人が判断**していた。
ドローンでは撮影は網羅取得を志向し、判断（トリアージ）が**後段（[2]）に移動**する。
これが手法としての本質的な違い（詳細 §5）。

## 2. 撮影仕様の実務目安（要裏取り）

【仮説】以下は二次情報（業界記事・レビュー要約）で挙げられる**実務目安**であり、業界標準として確定したものではない。JWPA・OEM仕様・契約仕様で必ず裏取りすること。

| 項目 | 一般的な値 | 補足 |
|---|---|---|
| GSD（地上分解能、1px が何mm相当か） | **1 mm/px 級**を要求する運用例がある | 0.1 mm 級は近接・後処理依存の特殊条件で、標準値ではない |
| 画像オーバーラップ | 連続画像で **60〜80%** | 後段のスティッチング・見落とし防止 |
| 離隔距離 | 数 m 〜 約 20 m | 近いほど高解像、衝突リスクと両立 |
| カメラ | 高解像度（数十MP〜100MP級）、望遠レンズ併用 | サーモ併用で、条件が合えば表層下欠陥の兆候を捉え得る（日射・材料・撮影時刻に依存） |
| 点検頻度 | 例：年次点検。厳しい環境では短縮される場合がある | メーカー推奨・保険・検査計画で変動 |
| 撮影条件 | ロータ停止・ロック、拡散光（曇天可）、逆光回避 | 無停止撮影技術もあるが内製初期は停止が標準 |

### 角度の原則

- 【観察】各面に**ほぼ正対（垂直）**して、ゆがみのない記録画像を撮るのが基本。
- 【仮説】前縁エロージョンは表面テクスチャ変化のため、**斜光（レイキングライト）**を当てると
  初期の凹凸・ピンホールが陰影で見えやすい。表面検査一般で確立した手法だが、
  ドローン点検仕様に組み込まれているかは原文・JWPAで要確認。

## 3. 損傷区分（重要度スケール）

【観察】一部のプロバイダでは5段階の重要度評価を用いる（細部はプロバイダ・運用により異なる）。POI は重要度カテゴリと同列の区分ではなく、緊急ではないが経過観察する箇所の管理枠である。

| 区分 | 内容の目安 |
|---|---|
| カテゴリ1 | 軽微な汚れ・無害な表面摩耗 |
| カテゴリ2 | 小さなクラック、局所的な塗装欠損 |
| カテゴリ3 | デボンディング、進行するクラック、熱異常 |
| カテゴリ4 | 大規模な層間剥離、コア損傷 |
| カテゴリ5 | 致命的損傷 |

※ JWPA ガイドラインの区分・判定基準はこれとは別系統。日本の実務では JWPA の判定区分が重要な参照指針になる（§5）。

## 4. 望遠鏡・ロープアクセス点検との違い

【観察】3手法は競合ではなく、性格が異なる。

| | 望遠鏡（地上光学） | ロープアクセス | ドローン撮影 |
|---|---|---|---|
| カバレッジ | 選択的・トリアージ型 | 1枚を集中・接触可 | 系統的・網羅型を目指す（実カバレッジは飛行制約等で要検証） |
| 記録 | 観察＋メモ中心 | メモ・写真（粒度は運用依存） | 網羅的な画像アーカイブにしやすい・経時比較可 |
| 接触検査 | 不可 | 可（打音・軟化部の触知） | 通常のRGBドローンでは不可（サーモで一部代替。研究・特殊機では接触/近接NDTも） |
| 高所作業 | なし | あり（危険・天候制約大） | なし |

### 手法を分ける本質：トリアージの位置

- 【観察】望遠鏡点検は撮影前に重点配分を人が決める（例：チップ〜中央スパンを重点、内側は簡易）。
- 【観察】ドローンは全面均一に撮り、重点判断を後段（解析）に回す。
- 【仮説】撮影段階では全スパンを均一に撮るべき（内側スパンの構造系損傷もあり、
  かつ均一データは選択バイアスがない）。重点配分は解析段階で行えばよい。
  → 旧手法の「選択的に撮る」習慣をドローン仕様に持ち込まないことが要点。

## 6. himinさんの劣化予測研究との接続

### 6.1 運用点検仕様 ≠ 研究グレード仕様

【研究設計上の提案】内製点検が始まっても、運用目的（損傷を見つけ報告書を作る）の仕様のままでは
劣化予測研究には不足する可能性が高い。研究には次の追加要件が要る（Claude Code による提案であり、観察事実ではない）：

- 生画像（RAW/高解像度）の長期アーカイブ
- 撮影位置・角度・距離の一貫性（経時比較の前提）
- 同一ブレードを固定間隔で反復撮影するスケジュール
- メタデータ粒度（タービンID／ブレードID／面／スパン位置／日時／気象）
- SCADA・気象データとの結合キー設計

→ 具体的な撮影設計は [drone_imaging_protocol.md](drone_imaging_protocol.md) を参照。

### 6.2 過去記録の不連続（注意点）

【仮説】望遠鏡・外注時代の点検記録は、重点配分により**外側スパンに厚く内側スパンが薄い**
偏りを持つ可能性がある。ドローン点検は全スパン均一になるため、過去記録と接続するとき
**データ密度の不連続**が交絡要因になる。内側スパンで「劣化が増えた」ように見えても、
観測密度が上がっただけかもしれない。外側スパン同士の比較の方がつなぎやすい。

### 6.3 社内レクチャーで投げるとよい質問

1. 生画像は破棄せず長期保存するか（報告書採用画像だけか）
2. 同一ブレード・同一スパンを毎回ほぼ同条件で撮る運用にできるか
3. 反復撮影の間隔は固定されるか
4. 画像にどこまでメタデータを紐付けるか
5. 点検画像を内部研究・大学院研究・対外発表に使う場合の許諾フローはどうなるか

**安全・法務・品質保証**

6. 飛行安全・航空法対応（飛行許可、風速上限、雷・降雨条件）の運用はどうなるか
7. ロータ停止・ロックアウトの手順と作業許可フロー
8. 点検画像の所有権・サイト所有者の同意・第三者提供・匿名化の扱い
9. 補修履歴と点検画像の紐付け（同一損傷の補修前後を追えるか）
10. カバレッジ・画質の品質保証（撮り漏れ・不鮮明画像の検出と再撮影の運用）

→ 5・8 は本研究のデータ基盤と権利処理の可否を左右する。データ蓄積前に枠組み化するのが望ましい。
