# 研究方向メモ：2D / 動画 / 3D の位置づけと将来構想（2026-04-13）

## 議論の経緯

himinさんとClaude Codeの対話から導出された研究方向の整理。

## 1. 2D-3D共存構造（確認済み）

他分野（医療・インフラ・建設・製造）のデータで裏付け済み。

```
2D画像：意思決定の記録・証拠（法的・契約的に残り続ける）
動画/3D：意思決定の根拠・補足（技術成熟に伴い追加される）
```

- 3Dが導入されても2D画像は消えない（法的証拠性・報告書互換性・コスト）
- 風力ブレード点検業界は現時点で画像がメイン（himinさんの現場確認に基づく）

## 2. 2Dスクリーニングの重要性

2D-3D二段階検査では、2D段階のRecall（見逃さない能力）がパイプライン全体のボトルネック。

- 現状Recall 0.49 → 損傷の半分を見逃す → 3D精密検査にも劣化予測にも到達しない
- Recall向上が最優先の改善課題

## 3. 動画の位置づけ

2Dと3Dの中間解として：
- 連続フレームで検出確率向上（Recall改善）
- 通常のドローン飛行で取得可能（特殊な撮影プロトコル不要）
- ただし現場では現時点で動画はあまり使われていない（画像がメイン）

## 4. 逆アプローチ：3D → 2D画像生成（将来構想）

### 概念
3D/動画を先に撮り、そこから標準化された証拠用画像を自動生成する。

### メリット
- 撮影条件の標準化（角度・距離・照明が毎回同じ）
- 経時比較の精度向上（同一視点からの差分比較）
- 1回のスキャンで証拠画像 + 3D解析の両方が得られる

### 課題
- 法的証拠性（生成画像が「撮影した写真」と同等に扱われるか未検討）
- コスト（現時点では直接撮影のほうが安い）
- テクスチャ品質（3D→2D変換で微細損傷が消える可能性）
- 業界の受容性

### 他分野の前例
- 医療CT：3Dボリューム → 2D断面画像生成（日常的）
- 建設BIM：3Dモデル → 2D図面自動生成（標準ワークフロー）

### 時期
- 現在：非現実的（コスト・制度）
- 5-10年後：医療CTと同様の道筋で標準化される可能性
