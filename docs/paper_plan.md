第一候補

風車ブレードの表面損傷スコアと運転荷重指標を用いた劣化進行リスク評価

研究の中心問い

同一タービンにおける表面損傷スコアと荷重履歴指標を組み合わせることで、ブレード劣化進行リスクを実務に有用な精度で評価できるか。

なぜこれが良いか
	•	あなたの現場知見が活きる
	•	画像系の今の成果をそのまま使える
	•	OpenFAST/DEL基盤をそのまま使える
	•	「補修箇所の1年後を知りたい」という動機に最も近い
	•	修士でも博士でも伸ばせる

必要データ
	•	同一タービンの点検画像
	•	同時期のSCADA
	•	できれば補修履歴
	•	気象イベント履歴
	•	可能なら故障/停止記録

修士なら何をやるか

	•	画像損傷スコアを定義
	•	DEL/負荷指標を推定

博士まで行くなら
	•	経年データを入れる
	•	進行速度モデルへ進む
