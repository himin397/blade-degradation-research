# ブレード研究用ドローン撮影プロトコル

**作成日**: 2026-04-14
**目的**: 研究価値を最大化するブレード画像の撮影方法を定義する
**前提**: 会社の公式な許可が取れた場合の撮影指針（許可なしでの個人撮影は不可）

---

## 撮影の5原則

### A. 同一箇所の経時追跡（最重要）

```
┌──────────────────────────────────────────────┐
│                                              │
│    [同じブレードの同じ箇所を時間差で撮る]    │
│                                              │
│   2026-06-01      2026-12-01    2027-06-01   │
│        │               │              │       │
│     📷─┼───→ 📷─────────┼──────→ 📷──┤       │
│        │               │              │       │
│     初期状態       3ヶ月後     9ヶ月後        │
│                                              │
└──────────────────────────────────────────────┘
```

| 項目 | 推奨方法 |
|---|---|
| 撮影頻度 | **3〜6ヶ月に1回**の定期撮影 |
| 同一性の担保 | タービンID、ブレードID（A/B/C）、位置ラベル（Tip/Mid/Root）を全画像に記録 |
| 撮影条件 | 毎回**同じ距離・同じ角度・同じズーム**（差分比較の前提） |

---

### B. 角度の多様性（3D再構成用）

```
        🎯 損傷箇所
       ／｜＼
      /  |  \
     /   |   \
   📷  📷📷  📷        ← 複数角度から撮る
  (60°) (90°) (120°)
  上斜め 正面  下斜め
```

**1つの損傷箇所を最低5-7枚、複数角度から撮影**。SfM（Structure from Motion）で3D化できる。

| 角度 | 目的 |
|---|---|
| 正面（90°） | 2D損傷検出の標準データ |
| 斜め上（約60°） | 深さ方向の情報 |
| 斜め下（約120°） | 同上、逆方向 |
| 左斜め（-30°） | SfM用 |
| 右斜め（+30°） | SfM用 |
| 接写 | 損傷の詳細形状 |
| 引き | 損傷位置の文脈 |

---

### C. 撮影メタデータの必須記録

| データ | 理由 |
|---|---|
| 撮影日時（秒単位） | 経時追跡の軸 |
| GPS座標（緯度・経度・高度） | タービンの特定 |
| ドローン姿勢（ピッチ・ヨー・ロール） | 撮影角度の再現 |
| カメラ設定（絞り・ISO・焦点距離・シャッター速度） | 照明条件の補正 |
| 気象条件（天候・風向・風速・気温・湿度） | 撮影条件の交絡因子 |
| タービンID / ブレードID / 部位ラベル | 経時追跡のキー |

**DJI系ドローンならEXIFに多くが自動記録される**。手動で追加すべきはタービンID・ブレードIDのみ。

---

### D. 照明条件の統一

```
    ☀ 太陽（高度）
   /
  /        × 避ける：強い直射、逆光
 / ブレード    
==============    ○ 推奨：朝9-11時、夕方15-17時
                        快晴 or 薄曇り
```

| 条件 | 推奨 | 避ける |
|---|---|---|
| 時間帯 | 朝9-11時 / 夕方15-17時 | 正午（影が真下） |
| 天候 | 快晴 / 薄曇り | 強風、雨後すぐ |
| 光の向き | 順光または側光 | 逆光（シルエットになる） |

---

### E. 撮影パターン（1タービンあたり）

```
┌─────── ブレード全体（引き）───────┐
│                                    │
│         ╔═══╗                      │
│        ╔╝   ╚╗   ← Tip（翼端）    │
│       ╔╝     ╚╗                   │
│      ╔╝       ╚╗  ← Mid（中央）  │
│      ║         ║                   │
│      ║         ║  ← Root（付根）  │
│      ╚═════════╝                   │
│                                    │
└────────────────────────────────────┘
```

| レベル | 撮影内容 | 枚数目安 |
|---|---|---|
| 1. 全体俯瞰 | ブレード全長が入る引きの画 | 3枚（3ブレード分） |
| 2. 部位別 | Tip / Mid / Root 各部の中距離画 | 9枚（3ブレード × 3部位） |
| 3. 損傷詳細 | 個別損傷の接写（角度多様性付き） | 5-7枚/損傷 × 損傷数 |

## 同一性担保のためのラベリング規則（推奨）

### ファイル名の例

```
YYYYMMDD_WTxx_BladeA_Mid_damage01_angle90.jpg

例：
20260601_WT01_BladeA_Mid_LE_damage01_angle90.jpg
20260601_WT01_BladeA_Mid_LE_damage01_angle60.jpg
20260601_WT01_BladeA_Mid_LE_damage01_angle120.jpg
                                       ↑
                                  角度を変えて複数枚
```

| 要素 | 意味 |
|---|---|
| YYYYMMDD | 撮影日 |
| WTxx | タービン番号（WT01, WT02...） |
| BladeA/B/C | ブレード識別（3枚のうちどれか） |
| Tip/Mid/Root | スパン方向位置 |
| LE/TE | 前縁/後縁 |
| damage01 | 損傷ID（同一箇所は同じ番号） |
| angle90 | 撮影角度 |

この規則で撮れば、**2年後の撮影と1対1で対応付け可能**になります。

---

## 経時比較のためのKey：損傷ID追跡

損傷が新規に発生した場合、IDを割り振って**2回目以降も同じIDで撮る**：

```
2026-06: WT01_BladeA_Mid_LE_damage01（新規発見、長さ5cm）
2026-12: WT01_BladeA_Mid_LE_damage01（6ヶ月後、長さ7cm）← 進行を追跡
2027-06: WT01_BladeA_Mid_LE_damage01（1年後、長さ10cm）

2027-06: WT01_BladeA_Mid_LE_damage02（新規発見）← 別IDで追加
```

これが**劣化進行予測の基盤データ**になります。

## 注意事項（中立性のために）

| リスク | 対処 |
|---|---|
| 画像の著作権 | 業務撮影は会社所有。個人使用には会社の許可が必須 |
| 顧客の機密情報 | サイト名・場所を匿名化。論文発表時は所有者の許可 |
| データ持ち出し規則 | 会社のデータ管理規程を確認 |
| 安全規則 | 飛行許可・天候制限・作業計画書 |

**「業務中に自分用に撮る」は会社のリソース（ドローン、時間、アクセス権）を個人目的に転用することになるため、必ず公式な許可を得てから実施する。**

## 推奨される進め方

### Step 1: 会社への研究協力依頼（現在）

- 「大学院の研究として、点検画像を匿名化して使わせてほしい」
- 研究成果のO&M改善への還元を提案
- **win-winの構造を設計**

### Step 2: 公式プロジェクト化

- O&M技術部門やデータ分析部門との連携
- 研究開発予算や業務時間として位置づける

### Step 3: サイト所有者の同意

- 画像使用許可を書面で取得
- 匿名化の範囲を明確化

### Step 4: 撮影プロトコルの確立

- 本ドキュメントのA-E原則に従う
- 初回撮影 → 3ヶ月後撮影 で経時追跡開始

---

## 撮影プロトコルの研究的価値

1. **経時追跡データは世界的に不足している**（Paper 3のfirst-order bottleneck）
2. **同一タービン×複数時点×複数角度のデータセットは公開されていない**
3. 仮にhiminさんが3年分のデータを取得できれば、それ自体が論文の独自性になる
4. データセットを匿名化して公開すれば、世界中の研究者に使われる可能性

## 使用機材：DJI Mavic 4 Pro（2025年モデル）

### 3カメラ構成の使い分け

| カメラ | 焦点距離 | 解像度 | 用途 | 推奨距離 |
|---|---|---|---|---|
| 広角 | 28mm | 100MP (4/3型) | 全体俯瞰・部位別 | 30-50m |
| 中望遠 | 70mm | 48MP (1/1.3型) | 部位別中距離 | 15-25m |
| 望遠 | 168mm | 50MP (1/1.5型) | 損傷接写 | 10-20m |

### 100MPカメラの活かし方

1枚でブレード全体を撮影し、後処理でTip/Mid/Rootに分割可能：

```
100MP画像（12288×8192）
  ↓ 後処理クロップ
  ├─ Tip部分（約3000×3000）
  ├─ Mid部分（約3000×3000）
  └─ Root部分（約3000×3000）
```

**DTU元画像（5280×2970px）の約6倍の情報量**。研究用として十分以上。

### Waypoint Mission（自動飛行）の活用

経時追跡の一貫性を担保する核心機能：

```
初回：手動で最適な飛行ルートを記録
  ↓
3ヶ月後：同じウェイポイントで自動飛行
  ↓
GPS精度内で同じ角度・距離を再現
```

### 推奨撮影設定

| 項目 | 推奨値 | 理由 |
|---|---|---|
| 撮影モード | Manual | 同条件を保つ |
| ホワイトバランス | 固定（5500K） | Autoは毎回変わる |
| ISO | 100-400 | ノイズ最小化 |
| シャッター速度 | 1/500秒以上 | 揺れ防止 |
| 絞り（広角） | f/5.6 | 解像度最良域 |
| 絞り（望遠） | f/8 | 被写界深度確保 |
| 画像形式 | **RAW + JPEG** | RAW=後処理用、JPEG=確認用 |
| 連写 | 3枚ブラケット | 最良の1枚を選択可能に |

### 動画機能の研究的活用

- **6K/60fps**：周回動画 → フレーム切り出し → SfM 3D再構成
- **4K/120fps**：回転中のブレード詳細観察
- **ホバリング長時間録画**：同一箇所の大量サンプリング
