## 1. 要点（判断）

- この研究の統計は、**工学の信頼性解析が本体**（ワイブル・打ち切り）で、そこに**生態学に近いデータの扱いにくさ**（野外の観察・入れ子）と、**機械学習の予測検証**が加わる形
- 分野の中での統計の負担は**平均よりやや重い側**。手法の高さは中くらいだが、データの扱いにくさが重い
- **予測に留める限り、経済学型の因果の識別（差の差分法・操作変数など）は必須ではない**。介入の効果（例：補修材が効く）を主張する時に初めて必要になる

## 2. この研究のデータに特有の難しさ

| 難しさ | 中身 | 必要になる手法 | 関係するフェーズ |
|---|---|---|---|
| 打ち切り | 観測を終えた時点でまだ補修閾値に達していないブレードは寿命が不明。平均を取ると寿命を短く見積もる | 生存時間解析（Kaplan-Meier・ワイブル回帰） | Phase 2（損傷進行） |
| 入れ子 | サイト → 風車 → ブレード。同じ風車の3枚は独立ではない | 階層モデル（混合効果・階層ベイズ） | Phase 2〜4 |
| 時間の向き | 今年の損傷は去年の損傷に依存する | 時系列・確率過程（ガンマ過程など） | Phase 2・3 |
| 少ない n | 風車は数十基単位で増やせない | 検証の不確かさの明示（大量データの機械学習の習慣は持ち込めない） | 全フェーズ |
| 観察データ | 補修材も点検時期も研究のために割り振ったものではない | 予測に留めるか、因果推論（介入の主張をする場合のみ） | Phase 2 以降 |

フェーズとの対応は `research_roadmap.md` のフェーズ名に当てた Claude Code の判断。

## 3. 研究設計で起きやすい落とし穴（基礎統計の範囲で説明できるもの）

計算は正しくても結論が崩れる場面。論文ドラフトの自己点検に使える。

1. **独立性の水増し**：同じ風車の複数年・複数ブレードを独立な n として数えると、検定が通りやすくなる（擬似反復）
2. **見せかけの関連**：機種と損傷率の関連が、機種ごとの設置環境（海沿い・内陸）の違いで生じている
3. **選択バイアス**：技術者が損傷の程度を見て補修材を選んでいると、補修材の比較は補修材の効果を表さない
4. **多重検定**：SCADA 変数50個を5%水準で検定すれば、全部無関係でも約2.5個が有意になる。調べる変数を先に決めておく（素粒子物理の look-elsewhere effect と同じ問題）

詳細と確認範囲は元の調査ノート §2。

| 分野 | 実態 | 出典 |
|---|---|---|
| 心理学 | 2017年の米欧主要誌288本・分析663件で ANOVA 20.81%・回帰 12.37%・SEM 系 9.65%・多水準回帰 3.77% | Blanca et al. (2018) Frontiers in Psychology |

## 5. 研究への示唆（判断）

1. 手法を借りる先は**信頼性工学（打ち切り・ワイブル）と生態学（階層モデル）**。データの形が最も近い
2. **NIST ハンドブック第8章（信頼性）**は無料の一次資料で、生存時間解析の入口の教材候補 https://www.itl.nist.gov/div898/handbook/
3. 予測モデルを作る時も、数十基のデータでは検証の不確かさ（区間・ばらつき）を示す
4. 「補修の効果」を研究の問いに選ぶ場合は因果推論が必要になり、統計の負担が経済学の側に寄る。問いの選び方で必要な手法が変わる点は、問いを決める時の判断材料になる（問いの設定は himinさん の担当）
