# 風車ブレードの構造：なぜこう作られているか

**目的**: ブレードの各構造要素が「なぜ必要か」を力学的に理解する
**前提**: 現場でブレードに登り、補修した経験がある（構造は見たことがある）

---

## 1. ブレードにかかる力

ブレードは運転中に主に3種類の力を受ける。すべての構造設計はこの3つの力に耐えるためにある。

```
         風 →
         
    ┌─── Tip（先端）
    │      ↑ フラップ方向（面外）：風を受けて前後にたわむ
    │      ← エッジ方向（面内）：自重 + 回転で上下に振られる
    │      ↻ ねじり：風の角度変化でブレードがねじれる
    │
    │
    │
    └─── Root（根元）→ ハブに接続
```

| 力の種類 | 方向 | 主な原因 | 最も厳しい場所 |
|---|---|---|---|
| フラップ曲げ | 風に押される方向（面外） | 風圧（揚力） | 根元（モーメント最大） |
| エッジ曲げ | 回転面内の上下方向 | 自重 + 重力の周期変動 | 根元 |
| ねじり | ブレード軸周りの回転 | 空力中心と剛性中心のずれ | 先端付近 |

**重要**: フラップ曲げが最も大きい。ブレードの主構造（スパーキャップ + シアウェブ）はこのフラップ曲げに耐えるために設計されている。

## 2. ブレードの断面構造

ブレードを輪切りにすると、翼型の断面が見える。

```
              前縁（Leading Edge）
                ╱ ╲
        ╱─────────────────╲
上面 → │ ┌───────────────┐ │
       │ │ スパーキャップ（上）│ │ ← UD繊維の積層。圧縮を受ける
       │ └───────────────┘ │
       │    │ シアウェブ │    │ ← 上下を繋ぐ壁。せん断を受ける
       │ ┌───────────────┐ │
下面 → │ │ スパーキャップ（下）│ │ ← UD繊維の積層。引張を受ける
       │ └───────────────┘ │
        ╲─────────────────╱
                ╲ ╱
              後縁（Trailing Edge）
```

## 3. 各構造要素の役割

### 3.1 スパーキャップ（Spar Cap）

**何か**: ブレードの上面と下面に配置された、翼弦方向25〜35%付近の厚い積層体。

**なぜ必要か**: フラップ曲げモーメントを受け持つ主構造。

力学的な説明：
```
風 →  ブレードが押される → 上面は圧縮、下面は引張を受ける

        圧縮 ← ← ← ← ←
    ┌────────────────────┐ 上面スパーキャップ
    │                    │
    │                    │  中立軸
    │                    │
    └────────────────────┘ 下面スパーキャップ
        → → → → → → 引張
```

I型鉄骨のフランジと同じ役割。上下に材料を集中させることで、最小の重量で最大の曲げ剛性を得る。

**材料**: 主にUD（一方向）ガラス繊維。大型ブレードでは炭素繊維も使用。繊維がブレードのスパン方向（長手方向）に揃っており、引張/圧縮に強い。

**根元から先端への変化**: 根元は厚い（曲げモーメントが最大）→ 先端に向かって薄くなる（モーメントが小さくなる + 軽量化）。

---

### 3.2 シアウェブ（Shear Web）

**何か**: 上下のスパーキャップを繋ぐ垂直な壁。1枚または2枚。

**なぜ必要か**: 2つの役割がある。

**役割 1: せん断力の伝達**

風の力はブレードの長さ方向に分布している。この分散した力を根元に伝えるとき、断面内に「せん断力」が発生する。シアウェブがこれを受け持つ。

```
段ボールの例え：

段ボール = サンドイッチ構造
  上の紙 = 上面スキン
  波の部分 = シアウェブに相当
  下の紙 = 下面スキン

波の部分がないと、上下の紙がずれて強度が出ない。
シアウェブがないと、上下のスパーキャップが独立に動いてしまい、
ブレードとして機能しない。
```

**役割 2: 断面形状の維持**

シアウェブがないと、風圧でブレードの断面がつぶれる（座屈）。上下を繋ぐことで翼型の形を保つ。

**材料**: ±45°のバイアキシャル（二軸）ガラス繊維 + フォームまたはバルサのサンドイッチ構造。±45°にすることでせん断に強い。

---

### 3.3 スキン（外板）/ シェル

**何か**: ブレードの外側を覆うシェル。翼型の空力的形状を作る。

**なぜ必要か**: 3つの役割。

1. **空力的形状の維持**: 風を効率よく受けるための翼型を形成
2. **面外荷重の分配**: 風圧をスパーキャップとシアウェブに伝達
3. **環境保護**: 雨、UV、雷、砂塵からの保護

**材料**: バイアキシャルまたはトライアキシャルのガラス繊維 + フォーム/バルサのサンドイッチ構造。

```
スキンのサンドイッチ構造（拡大）：

  ┌──────────────┐  外側FRP層（0.5〜2mm）
  │ ▒▒▒▒▒▒▒▒▒▒▒▒ │  フォームまたはバルサ芯材（5〜50mm）
  └──────────────┘  内側FRP層（0.5〜2mm）
```

サンドイッチにする理由: 薄いFRP1枚では曲げ剛性が足りず座屈する。間にフォームを挟むと、重量をほとんど増やさずに曲げ剛性が大幅に上がる。

---

### 3.4 前縁（Leading Edge）

**何か**: ブレードの風を最初に受ける部分。

**なぜ重要か**: 空力性能に最も影響する部分。前縁の形状が崩れると揚力が減り、Cp が下がる。

**なぜ傷みやすいか**:
- 先端に行くほど周速が大きい（先端で 80〜90 m/s）
- 雨滴、砂塵、虫がこの速度で衝突する → エロージョン
- 前縁保護テープ（LEP）が劣化するとFRPが露出する

**himinさんの研究との接続**: Paper 1 の LE;ER（前縁エロージョン）が最も検出数の多いクラスだったのは、前縁が最も傷みやすい構造だからである。

---

### 3.5 後縁（Trailing Edge）

**何か**: ブレードの風が最後に離れる部分。

**構造的な特徴**: 上面シェルと下面シェルが接着剤で貼り合わされている。ブレード断面の中で最も薄い。

**なぜ問題が起きやすいか**: 接着面積が小さく、エッジ方向の繰り返し荷重（開閉モード）で接着部が剥離しやすい。

---

### 3.6 根元部（Root Section）

**何か**: ブレードをハブに接続するボルト穴が並ぶ円筒部。

**構造的な特徴**:
- 翼型ではなく円形断面
- 壁が非常に厚い（曲げモーメントが最大のため）
- 鋼製のブッシングが埋め込まれている

**根元からの遷移**: 円形断面から翼型断面への遷移区間が存在する。この区間は応力集中が起きやすく、設計上重要。

---

## 4. 繊維方向と力の関係

ブレードの各部位で繊維の向きが異なる。これは受ける力の方向に合わせている。

| 繊維方向 | 強い力の方向 | 使う場所 |
|---|---|---|
| 0°（スパン方向） | 引張 / 圧縮（長手方向） | スパーキャップ |
| ±45° | せん断 | シアウェブ、スキンの一部 |
| 90°（翼弦方向） | 翼弦方向の圧縮 | スキンの補強 |
| トライアキシャル（0/±45） | 複合的 | スキン全般 |

```
  0° ────────  スパン方向（ブレードの長さ方向）
 +45° ╱╱╱╱╱╱  
 -45° ╲╲╲╲╲╲  → これらを組み合わせてせん断に抵抗
  90° │││││││  翼弦方向
```

## 5. 根元から先端への変化

ブレードは「先端に行くほど薄く、軽く、柔らかく」なる。

```
根元                              先端
├──────────────────────────────────┤

断面サイズ：  大 ──────────→ 小
壁の厚さ：   厚い ────────→ 薄い
スパーキャップ：厚い ────────→ 薄い
剛性：       高い ────────→ 低い（たわみやすい）
翼型の厚み比：厚い翼型 ────→ 薄い翼型

荷重（曲げモーメント）：最大 ──→ ゼロ（先端は自由端）
周速：       低い ────────→ 最大（エロージョンリスク最大）
```

**重要な矛盾**: 先端は構造的に薄く弱いが、周速が最も高くエロージョンを受けやすい。かつ先端のたわみが最も大きい。これが先端部の損傷が特に注意すべき理由。

---

## 6. 表面保護層（外側から順）

ブレード表面は複数の層で保護されている。

```
外側 ←──────────────────── 内側

ゲルコート（0.3〜0.5mm）
  │  塗料（紫外線保護）
  │    │  前縁保護テープ（LEP）※前縁のみ
  │    │    │  トップコート
  │    │    │    │  FRP積層（スキン外層）
  │    │    │    │    │  フォーム/バルサ芯材
  │    │    │    │    │    │  FRP積層（スキン内層）
```

エロージョンの進行はこの順に外側から浸食する：
1. ゲルコート/LEPの摩耗・剥離
2. FRP最外層の露出
3. 繊維の露出・破断
4. 芯材への浸水 → 内部劣化の加速

## 7. よくある損傷と構造的原因

| 損傷タイプ | 構造的原因 | 発生しやすい場所 |
|---|---|---|
| 前縁エロージョン | 高周速での雨滴/砂塵衝突 | 先端〜中間の前縁 |
| 前縁亀裂 | エロージョン進行 + 繰り返し荷重 | 前縁（特に先端側） |
| 後縁の剥離 | 接着部へのエッジ方向繰り返し荷重 | 後縁接合部 |
| シアウェブ剥離 | スパーキャップとの接着部への疲労荷重 | シアウェブ接合線 |
| 雷撃損傷 | 落雷による局所的な熱・衝撃 | 先端のレセプター付近 |
| 表面塗装の劣化 | 紫外線 + 温度変化 + 機械的摩耗 | 全面（特に前縁） |

## 8. バランスチャンファー（Balance Chamfer）について

**何か**: ブレードの重量バランスを調整するために、特定の箇所を斜めに削る加工。

**なぜ必要か**: 3枚のブレードの重量と重心位置が完全に一致していないと、回転時に振動が発生する。製造公差による重量のばらつきを補正するために：

1. 各ブレードの重量と重心位置を測定
2. 重い側を削る（チャンファー加工）、または軽い側にバランスウェイトを追加
3. 3枚のブレード間でモーメントバランスを揃える

```
   ブレード1: 12,050 kg  重心位置 15.2m
   ブレード2: 12,080 kg  重心位置 15.3m  ← 少し重い → チャンファーで調整
   ブレード3: 12,045 kg  重心位置 15.1m

   許容範囲内にバランスを合わせる
```

バランスが崩れると：
- ローターの回転ごとに周期的な振動が発生
- タワー、ナセル、軸受への疲労荷重が増大
- 極端な場合は共振による構造破壊のリスク
