## 1. YOLOv8とは

YOLO（You Only Look Once）は画像から物体を検出するAIモデルの一種。
"One Stage"と呼ばれる手法で、画像を一度見るだけで「何が・どこに」あるかを同時に予測する。

```
入力画像
   ↓
YOLOv8（CNNで特徴抽出）
   ↓
バウンディングボックス（座標）+ クラス（損傷種別）+ 信頼度スコア
```

先行研究（Shihavuddin 2019）はFaster R-CNNという「2段階」の手法を使った。
YOLOv8は1段階なので速度が速い代わりに、小さな物体の検出が若干苦手な傾向がある。

### モデルサイズ

| 名称 | パラメータ数 | 速度 | 精度 |
|---|---|---|---|
| YOLOv8n（nano）| 3M | 最速 | 低め |
| YOLOv8s（small）| 11M | 速い | 中 |
| YOLOv8m（medium）| 25M | 中 | 高め |
| YOLOv8l（large）| 43M | 遅い | 高い |
| YOLOv8x（extra）| 68M | 最遅 | 最高 |

本研究のベースラインはnano（最軽量）から始め、結果を見てサイズを上げるかを判断する。

```

```

| 指標 | 意味 | 方向 |
|---|---|---|
| box_loss | バウンディングボックスの座標誤差 | 下がるほど良い |
| cls_loss | クラス分類の誤差 | 下がるほど良い |
| dfl_loss | Distribution Focal Loss（座標精度） | 下がるほど良い |
| GPU_mem | 使用メモリ量 | 参考値 |

**1エポック目でmAPが0に近いのは正常。** モデルはまだランダムな重みから学習を始めたばかり。

## 3. mAPの読み方

mAP（mean Average Precision）は物体検出モデルの総合評価指標。

### まずPrecisionとRecallを理解する

```
検出結果の分類：
  TP（True Positive）:  損傷があり、正しく検出した
  FP（False Positive）: 損傷がないのに、あると誤検出した
  FN（False Negative）: 損傷があるのに、見逃した

Precision = TP / (TP + FP)  ← 検出したもののうち、本当に正しかった割合
Recall    = TP / (TP + FN)  ← 実際の損傷のうち、見つけられた割合
```

**現場での直感**：
- Precisionが低い → 「損傷あり」と言ったのに実際は違うケースが多い（過検出）
- Recallが低い → 本物の損傷を見逃している（見落とし）
- 風車点検では**Recallを優先**することが多い（見逃しの方がリスクが高いため）

### AP（Average Precision）

信頼度スコアの閾値を変えながらPrecision-Recallをプロットし、曲線の面積を求めたもの。
1クラスごとに計算される（0〜1）。

### mAP = 全クラスのAPの平均

```
mAP = (AP_VG;MT + AP_LE;ER + AP_LR;DA + AP_LE;CR + AP_SF;PO) / 5
```

### mAP@0.5 と mAP@0.5:0.95 の違い

| 指標 | IoU閾値 | 意味 |
|---|---|---|
| mAP@0.5 | 50% | 予測ボックスと正解ボックスが50%以上重なれば正解 |
| mAP@0.5:0.95 | 50%〜95%の平均 | より厳密な評価。座標精度も問われる |

**IoU（Intersection over Union）**とは、予測ボックスと正解ボックスの重なり度合い。

```
IoU = 重なり面積 / 合計面積（和集合）

IoU = 0.5 の意味：
  予測ボックスが正解ボックスと半分以上重なっていれば「当たり」とみなす
```

### 本研究の目標値（Phase 1）

| 指標 | 目標 | 先行研究（参考） |
|---|---|---|
| mAP@0.5 | 0.50以上（ベースライン） | 0.811（Faster R-CNN + 高度なAug） |
| mAP@0.5 | 0.70以上（改良後） | - |

先行研究との差は手法（Faster R-CNN vs YOLOv8）・拡張手法・エポック数の違いがあるため、
単純比較ではなく「LE;ERクラス単体の精度」に着目して比較する。
