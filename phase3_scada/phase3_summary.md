## 3. 疲労リスク代理指標（月次）

### 指標定義

| 指標 | 説明 | 根拠 |
|---|---|---|
| hrs_above_rated | 定格風速（>12m/s）超の運転時間（時間/月） | 高風速 = 高荷重 = 疲労蓄積の代理 |
| mean_ti | 月平均乱流強度（風速ビン内σ/μの平均） | TI高 = 荷重変動大。エロージョン感応域（9-13m/s）での影響が大（Malik & Bak 2025） |
| hrs_high_ti | TI>0.15かつ風速>4m/sの時間（時間/月） | 荷重変動の激しい運転時間の代理 |
| fatigue_risk_score | 上記3指標の正規化加重和（等重み・暫定） | 複合リスク指標 |

## 4. 考察

### うまくいったこと
- パイプライン全体（前処理→パワーカーブ→特徴量→CSV）が動作
- `hrs_above_rated` は季節変動（冬・夏に高風速が多い）を捉えている
- 疲労リスクスコアの構造（複合指標）はPhase 4統合パイプラインへそのまま接続可能

### 制約・限界
- `hrs_high_ti = 0` 全月：このタービンはTI < 0.15の低乱流環境。閾値が高すぎた可能性もあるが、データの実態を反映している
- TIはナセル風速計1点計測。ブレード面のTI分布は反映していない
- 月次集計のため短期イベント（暴風・台風）の影響が平滑化されている
- 代理指標の重みは等重み（暫定）。物理モデル（疲労累積則）による重み設定はPhase 5以降

### 仮説（仮説止まり）
- 8月の疲労リスクスコア最高（0.482）は、夏季の定格超え運転が多いことに起因
- mean_TIが夏季（7月: 0.039）に最高値を示すのは熱的乱流の影響の可能性

## 5. Phase 4への引き継ぎ

Phase 3で算出した月次疲労リスクスコアを、Phase 1の画像リスクスコアと接続するパイプラインをPhase 4で設計する。両者は別タービンのデータだが、「型（構造）」として実装し、自社データ投入時に即動作可能な状態を目指す。
