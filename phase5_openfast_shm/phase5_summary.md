## 2. 簡易ブレード荷重モデル

### モデル定式（IEC 61400-1 / Sutherland 1999参考）

```
I_fatigue(V, TI) = (V / V_rated)^n × CT(V) × (1 + γ × TI)
```

| パラメータ | 値 | 根拠 |
|---|---|---|
| n = 3 | 疲労損傷の風速指数 | 荷重∝V²・等価サイクル∝V の積（IEC 61400-1 Annex H参考） |
| γ = 5 | TI増幅係数 | Sutherland 1999 "On the Fatigue Analysis of Wind Turbines" |
| m = 10 | SN曲線指数 | GFRPブレード材料（DNV GL 2016） |
| CT(V) | スラスト係数カーブ | V≦V_rated: 0.80, V>V_rated: 0.80×(V_rated/V)² |

### DELプロキシ算出式
```
DEL_proxy_month = (mean(I_fatigue^m))^(1/m)
```
SN則によるDamage Equivalent Load（DEL）の月次集計値。

## 4. 相関分析結果と物理的解釈

### 相関係数

| 指標 | Pearson r | p値 | 解釈 |
|---|---|---|---|
| hrs_above_rated vs DEL | **+0.808** | 0.001 | 強い正相関（予想通り） |
| mean_ti vs DEL | **-0.899** | <0.001 | 強い**負**相関（要注意） |

### なぜ mean_ti が負相関になるのか（Simpson's Paradox）

一見矛盾するが、このサイト固有の季節パターンが原因：

```
夏季（6〜8月）: TI高（熱的乱流・最大0.047）× 風速低（DEL低）
冬〜春（1〜3月）: TI低（0.027〜0.035）× 風速高（DEL高）
```

→ **交絡変数「風速」により、TIと DELの見かけ上の負相関が生じる**

物理的真実：「同じ風速でTIが高いほどDELは増加する」（本モデルの乗算項で正しく実装）
観測された負相関：「高TI月＝低風速月」という部位固有の季節パターン

### 重み較正結果

| | hrs_above_rated 重み (α) | mean_ti 重み (β) |
|---|---|---|
| Phase 3等重み（暫定） | 0.500 | 0.500 |
| **Phase 5較正（単純OLS）** | **1.000** | **0.000** |

**解釈**：このサイト（TI≈0.03〜0.05、IEC Class C以下）では、
乱流強度は疲労荷重への寄与が小さく、**高風速曝露時間が疲労を支配する**。

ただし、この較正は**IECクラスA・B相当サイト（TI≥0.14）では大きく変わる**。
本サイトの極低TI環境という特殊性を反映した結果である。

## 5. Phase 3等重み仮定の再評価

| 問い | 結論 |
|---|---|
| 等重みは妥当か？ | このサイトでは**hrs_above_rated**を主指標とすべき（TIの寄与は小さい） |
| TIを除外すべきか？ | 除外は過剰。TI > 0.10 環境（IEC Class B以上のサイト）では再評価が必要 |
| 一般化可能か？ | 不可。サイト特性（TIレベル）に依存する。普遍的モデルにはOpenFAST較正が必要 |

## 8. 制約・限界

1. **簡易モデルの非線形性無視**: 実際の荷重はブレード形状・翼型・ダイナミクスに依存
2. **CT曲線の単純化**: 実測CTカーブがないため、Betz理論に基づく近似使用
3. **サイト特殊性**: TI≈0.03〜0.05は極低乱流。一般化には複数サイト必要
4. **等価サイクル数**: DEL算出ではRainflow countingが必要だが、10分平均値から近似
5. **SN指数 m=10**: GFRPの典型値だが実機材料特性は未確認
