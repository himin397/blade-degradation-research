# Claude Code 判断ログ（ブレード劣化予測研究）

作成：2026-09-04。FRP 検証運用ルール「判断ログ」の記録先。

## 目的

Claude Code が「判断・仮説」ラベルで出した主張の**的中率を事後測定**する。個々の回答の質はその場で測れないが、生成者の的中率は決着後に測れる。数か月分たまれば「Claude Code の確度ラベルをどの程度信頼してよいか」の掛け目が実測で決まる。

**限界**：測定できるのは記録対象に選ばれた判断の的中率であり、全判断の代表サンプルではない（記録するか否かの選択も Claude Code 自身が行うため）。掛け目は「記録級の重要判断」に対するものとして解釈する。

## 運用

- Claude Code が重要な判断・仮説を出したら1行追記（軽微なものは記録しない。目安：研究結論・論文の主張・研究計画・卒論の進め方に影響するもの）
- 決着条件には**判定方法と判定期限**を書く（後から当たり判定を寄せるのを防ぐ）
- 決着したら「決着日・結果」を記入。結果は ○（当たり）／×（外れ）／△（部分的）
- 集計は**四半期末、または期限超過エントリに気づいた次のセッション冒頭**に実施
- 勤務先由来のデータ・サイト名・機器IDは書かない（守秘区分A）

## 確度の定義

| ラベル | 主観確率 |
|---|---|
| 高 | 80%以上 |
| 中 | 50〜79% |
| 低 | 50%未満 |
